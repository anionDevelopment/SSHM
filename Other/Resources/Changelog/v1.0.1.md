# Release notes

## Changes

- added non-code-stuff
- The codeunit implements the codeunit-specification-version 3.0.0 and its scripts use the current api of ScriptCollection (the function which determined the version does not exist anymore)
- The build of the bundled upstream now runs on a copy of it: the buildhelper of the upstream determines the folder it writes its logs and its intermediate results into by walking upwards until it finds a folder named ".git", which inside this repository is the one of SSHM itself, so it wrote outside of its own folder and the build failed
- The linting checks the own scripts of the codeunit instead of the sourcecode of the upstream, which must not be changed here
- Documented that the build needs the Windows-SDK and Visual Studio with the C++-workload, and that this codeunit is buildable on Windows only
