# SSHM reference

SSHM compiles the bundled Win32-OpenSSH-upstream (located at the repository-level folder `Other/Resources/Upstream`) and provides the resulting OpenSSH-for-Windows binaries as build-artifact (`Other/Artifacts/BuildResult_Win32OpenSSH_<arch>`).

This codeunit does not contain own source-code; see the upstream-repository for the documentation of the produced tools (`ssh`, `sshd`, `scp`, `sftp`, `ssh-keygen`, ...).
